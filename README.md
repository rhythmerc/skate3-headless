# skate3-headless

The Skate 3 skating simulation as a plain Rust library (crate `skate3-sim`): physics, the animation graphs, camera, grinding,
scoring, the HUD scripts, input gestures and the player-audio graph. It has no engine or renderer
dependency (no Bevy). You give it input and a world, step it, and read back poses, the board, the camera
frame, HUD state and audio.

It is the Skate 3 engine of [buildAR](https://github.com/rhythmerc/buildar), a Quest 3
AR skateboarding app. That app does all the rendering, and it uses this library the way it uses
[thug2-headless](https://github.com/rhythmerc/thug2-headless) for THUG2.

## You need your own copy of Skate 3

**No game data is in this repository.** The simulation runs on data converted from your own Skate 3
disc: the skater, animations, graphs and sounds. See the app's
[import guide](https://github.com/rhythmerc/buildar/blob/main/docs/IMPORT-SKATE3.md).

Without that data, the library builds and its asset-free tests run, but it can't load a skater.

## Crates

| Crate | What |
|---|---|
| `sim` (`skate3-sim`) | The simulation and its front interface: `Bundle::open`, `Sim::load`, `Sim::tick`, `PlayerAudio` |
| `engine` (`skate3-engine`) | Skate 3 as the [buildAR engine contract](https://github.com/rhythmerc/buildar-engine-core) (`engine_core::EngineCore`): stage, input, model, HUD, sound and the data it runs on. A host pins the same `engine-core` revision as this workspace |
| `skate-core` | Retail physics primitives, maths, the contact solver |
| `skate-data` | Readers for the converted data: maps, collision, graphs |
| `skate-audio-core` | The player-audio mixer and its graph primitives |
| `skate-audio-formats` | Audio container formats |

## Using it

As a git dependency, pinned by revision:

```toml
skate3-sim = { git = "https://github.com/rhythmerc/skate3-headless", rev = "<sha>" }
```

`glam` and `tracing` are pinned exactly (`=0.30.10`, `=0.1.44`), to the versions Bevy 0.18.1 uses. A
Bevy host can then pass `Vec3`, `Quat` and `Mat4` across without converting, and Bevy's log plugin
collects the sim's events.

## Tests

```sh
cargo test --release --workspace
```

About 120 tests are `#[ignore]`d. They need converted data, from `SKATE3_ASSET_ROOT` (and
`SKATE_ASSETS`, `SKATE_MAP_TEST_PATH` for a few):

```sh
SKATE3_ASSET_ROOT=/path/to/converted cargo test --release --workspace -- --ignored
```

The two binary test fixtures (`sim/tests/fixtures/format-demo.skate` and
`skate-data/tests/fixtures/retail-collision.rwcmset`) are generated by the app repo's
`tools/make_skate_demo.py` and `tools/make_collision_fixture.py`. They contain no game data.
